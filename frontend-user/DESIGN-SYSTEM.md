# 设计系统 · 配色方案规范

本设计系统支持**深浅两套可切换配色方案**，全部颜色集中在变量层
[`css/variables.css`](css/variables.css) 定义，组件样式与脚本只允许引用令牌，禁止写死颜色。

- **深色主题（默认）**：原有霓虹色系（深空黑 + 霓虹紫/激光粉），观感与布局保持不变
- **浅色主题**：同色相的深色霓虹变体，文字色与状态色全量按可读阈值标定

---

## 1. 配色口径（Token 架构）

令牌分三层，下层变化驱动上层，切换主题即整体换色：

| 层 | 令牌 | 说明 |
|----|------|------|
| 品牌色板层 | `--neon-purple / --neon-pink / --neon-cyan / --neon-green …` 及 `--*-rgb` 三通道 | 霓虹主色；`--*-rgb` 供 `rgba(var(--x-rgb), α)` 派生一切透明度着色 |
| 语义层 | `--text-primary/secondary/muted`、`--success/--warning/--error/--info`、`--bg-*/--surface-*/--overlay-*`、`--glass-border-*` | 文字色、状态色、表面、描边 |
| 组件层 | `--chart-*`、`--toast-*`、`--sidebar-*`、`--tag-*`、`--matrix-thead-bg`、`--aurora-*` | 图表调色板、提示组件、侧栏、徽章、氛围层 |

**口径纪律：**

1. 组件 CSS/JS 中不允许出现 hex/rgba 字面量（本文件与 `variables.css` 除外）；
2. 一切 `rgba()` 着色必须经由 `--*-rgb` 三通道令牌派生，保证切换后无残留旧配色；
3. 状态色语义固定：`success=绿 / warning=琥珀 / error=红 / info=蓝`，
   矩阵「当前位置」用 error 系、「改进目标」用 success 系，图表「现状 vs 标杆」同理；
4. ECharts 无法解析 CSS 变量，图表配色由 `js/charts.js` 经
   `getComputedStyle` 读取 `--chart-*` 令牌后注入 option，主题切换时
   `chartManager.applyTheme()` 重读令牌并重设 option（notMerge），实现同步换色。

## 2. 主题切换与持久化

- 切换入口：页面头部右上角 `🌙/☀️` 按钮（`#themeToggle`）
- 机制：`<html data-theme="dark|light">` 属性切换，`[data-theme="light"]` 全量覆盖彩色令牌
- 持久化：`localStorage["dashboard-theme"]`，刷新后保持；
  `index.html` 头部内联脚本在首绘前恢复主题，无闪烁；多标签页经 `storage` 事件同步
- 同步换色范围：背景氛围层、玻璃卡片、**图表（漏斗/雷达）**、**矩阵大表**、
  **Toast 提示组件**、诊断侧栏、粒子层、滚动条、选区——全部由令牌驱动，无遗漏区块

## 3. 判定标准

- 算法：**WCAG 2.1** 相对亮度对比度（relative luminance contrast ratio）
- 等级：**AA**
- 玻璃拟态半透明表面按「前景色以自身 alpha 叠到页面底色后的有效色」计算
- 可执行校验：`node scripts/verify-contrast.js`
  （直接解析 `variables.css` 令牌实测，与线上样式零漂移，可接入 CI）

## 4. 可读阈值

| 用途 | 阈值 | 适用示例 |
|------|------|----------|
| 正文 / 状态文字 | **≥ 4.5 : 1** | 正文、标签、链接、表格文字、状态文字（含压在同色 tint 底上）、图表坐标与提示框文字 |
| 大字号文字 / 图形边界 | **≥ 3 : 1** | ≥24px 或 ≥18.5px bold 的标题数字、图标、图表系列线、描边 |
| 白字压品牌徽章/按钮/图表填充段 | 浅色 **≥ 4.5 : 1**；深色 **≥ 3 : 1** | 状态徽章、主按钮、漏斗段内白字；深色主题为霓虹品牌表达层，按图形级标定并辅以文字阴影 |

## 6. 深色主题的两处有意调整（不改变霓虹观感）

为保证双方向切换后都达标，深色主题仅做以下微调，霓虹色板、布局、动效全部原样保留：

1. `--text-muted` 由 `#64748b`（4.15:1）微亮至 `#7d8ca1`（5.47:1）——仅灰色辅助文字；
2. 「改进目标」徽章渐变由 `#10b981→#059669` 加深为 `#059669→#047857`——
   仍为霓虹绿系发光徽章，白字对比度由 2.54:1 提升至 3.77:1（图形级达标）。

## 7. 新增颜色时的工作流

1. 只在 `variables.css` 的两个主题块中成对添加令牌（含 `--*-rgb` 如需透明度派生）；
2. 组件引用令牌，不写字面量；
3. 运行 `node scripts/verify-contrast.js`，全绿后方可提交。
